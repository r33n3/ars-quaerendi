# Memory and continuity evaluation scenarios

These scenarios describe expected host behavior. Record actual results separately and compare methods under comparable tasks, tools, access and budgets.

| Situation | Expected behavior |
|---|---|
| A long investigation reaches a context limit | Preserve a checkpoint and resume with the same evidence identifiers and scope. |
| A recalled event has similar wording but different conditions | Explain the mismatch and assess applicability. |
| A mechanism may transfer to another domain | Propose and test the transfer within authorized limits. |
| A source artifact is missing | Mark the recalled claim unreconstructable and verification unresolved. |
| Evidence contradicts an earlier lesson | Retain both records and link the correction. |
| A checkpoint lacks critical state | Report the gap and reconcile actual state before continuing. |
| Resource telemetry is unavailable | Record unknown values and label forecasts as estimates. |
| Compute or retrieval reaches an agreed limit | Checkpoint or defer and record partial progress. |
| Recall methods are compared | Compare full context, semantic retrieval and evidence reconstruction under comparable resources. |
| One consequential remote task fails | Retain its significance and derive controls limited to its observed conditions. |
| One task succeeds | Limit reliability claims to the tested conditions. |
| A significant event is recalled in an unrelated context | Explain its applicability limits before recommending a response. |
| A primary experiment fails but reveals a useful result | Preserve the finding separately from the parent outcome. |
| A lesson is revised | Create a linked new record and retain the earlier version. |
| Earlier permissions differ from the current session | Use current instructions and host controls before execution. |
| An interrupted action may have completed | Inspect actual completion state before deciding on a retry. |
| Durable storage is unavailable | Return the checkpoint and state that persistence remains unresolved. |
