# Discovery

## When to use
Investigate unexpected observations, patterns and promising leads. Use existing tools directly for routine tasks.

## Method
Record expected versus observed results, raw evidence, environment and provenance. Separate anomaly from interpretation. Test for instrument errors, confounders, coverage and coincidence. Change representation where helpful: bytes, hex, entropy, parsed structure, visualization, numerical patterns or execution traces. Develop alternative hypotheses and cheap discriminating tests. Record leads outside the current task for later investigation. Check prior work before claiming novelty and ask the user before changing the goal.

## Shared contract
- D documented; O directly observed; R independently reproduced; H hypothesis; U unknown; X contradicted.
- The person or host agent controls purpose, permissions, tool execution and collaboration.
- Support measurements, search results and execution claims with recorded evidence. Choose the smallest action that answers the next question.
- Report evidence, tested scope, limitations, progress and the reason for continuing or stopping.

See `references/` in the package for extended methods.
