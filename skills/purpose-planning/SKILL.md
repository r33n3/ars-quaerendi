# Purpose Planning: Goals and Work Plans

Use this skill to decide what work serves the user's purpose and how to approach it. It considers value, assumptions, effort, risks, dependencies and reasons to revise or stop a plan.

## When to use

Use when the desired outcome is broad, several tasks compete for attention or new evidence changes the plan. In meeting work, use it to turn agreed decisions into proposed follow up and identify missing owners or dates.

## Available tools

Choose methods that fit the tools and access available in the current session. Work from supplied material when access is limited. State which searches, tests or checks were completed, which remain unverified and what would be needed to complete them.

## Method
Read the user's purpose and constraints. Consider possible goals and whether the current goals are sufficient. For each goal, assess its value, assumptions, cost, risks and likelihood of success. Check how it serves the user's purpose and how easily its effects could be reversed. Plan milestones, dependencies and experiments. Set limits on time and resources, and state when to revise or stop the work. Update the plan as evidence changes. Obtain authorization for changes to the purpose or permissions.

## Expected result

Return proposed goals and priorities with reasons, milestones, dependencies, resource limits and review points. Distinguish agreed actions from suggestions that need a decision.

## Shared contract
* D documented; O directly observed; R independently reproduced; H hypothesis; U unknown; X contradicted.
* The person or host agent controls purpose, permissions, tool execution and collaboration.
* Support measurements, search results and execution claims with recorded evidence. Choose the smallest action that answers the next question.
* Report evidence, tested scope, limitations, progress and the reason for continuing or stopping.

See `references/` in the package for extended methods.
