# Purpose Planning

## When to use
Derive worthwhile goals from an existing authorized purpose. Do not invoke for routine tasks already solved by existing tools.

## Method
Read the stated purpose, constraints and user intent. Generate ordinary and lateral candidate goals, including no-new-goal. Evaluate purpose linkage, value, assumptions, feasibility, cost, reversibility and risks. Critique goal drift. Build bounded plans with milestones, dependencies, experiments, revision triggers and stop conditions. Update plans on evidence; never silently rewrite purpose or expand permissions.

## Shared contract
- D documented; O directly observed; R independently reproduced; H hypothesis; U unknown; X contradicted.
- Evidence level is not authorization. The person or host agent controls purpose, permissions, tool execution and any optional collaboration.
- Do not fabricate measurements, search results or execution. Prefer the smallest informative next action.
- Output scoped evidence, limitations, progress and a justified next step or stop.

See `references/` in the package for extended methods.
