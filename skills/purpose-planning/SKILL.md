# Purpose Planning

## When to use
Choose goals and plan work within the user's stated purpose. Use existing tools directly for routine tasks.

## Method
Read the stated purpose, constraints and user intent. Generate ordinary and lateral candidate goals, including continuing with the current goals. Evaluate purpose linkage, value, assumptions, feasibility, cost, reversibility and risks. Check that each goal serves the stated purpose. Build bounded plans with milestones, dependencies, experiments, revision triggers and stop conditions. Update plans as evidence changes. Obtain authorization for changes to the purpose or permissions.

## Shared contract
- D documented; O directly observed; R independently reproduced; H hypothesis; U unknown; X contradicted.
- The person or host agent controls purpose, permissions, tool execution and collaboration.
- Support measurements, search results and execution claims with recorded evidence. Choose the smallest action that answers the next question.
- Report evidence, tested scope, limitations, progress and the reason for continuing or stopping.

See `references/` in the package for extended methods.
