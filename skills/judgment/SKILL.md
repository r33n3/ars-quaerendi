# Judgment

## When to use
Calibrate evidence sufficiency without consensus voting. Do not invoke for routine tasks already solved by existing tools.

## Method
Identify claim, intended use, risk and reversibility. Select J0 exploratory, J1 plausible, J2 supported, J3 verified in tested scope, J4 qualified for specified deployment. Run deterministic tests and provenance checks first. Use at most one focused semantic challenge and bounded revision by default. A concrete counterexample outweighs unsupported votes. Missing evidence is inconclusive, not automatic failure. Return scoped proceed, limited, revise, request-evidence, escalate or stop; runtime owns authorization.

## Shared contract
- D documented; O directly observed; R independently reproduced; H hypothesis; U unknown; X contradicted.
- Evidence level is not authorization. Main agent owns purpose, orchestration, permissions, tool execution and P2P A2A trust.
- Do not fabricate measurements, search results or execution. Prefer the smallest informative next action.
- Output scoped evidence, limitations, progress and a justified next step or stop.

See `references/` in the package for extended methods.
