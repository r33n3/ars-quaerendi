# Toolcraft

## When to use
Acquire or create minimal tools with ephemeral-first experimentation. Do not invoke for routine tasks already solved by existing tools.

## Method
Identify exact missing capability versus knowledge, configuration or authorization gap. Prefer existing local tools or other authorized resources, then configure, compose, extend or build as needed. Investigate undocumented interfaces via exports, headers, symbols, observed errors, ownership and version-specific behavior. Build minimal probes in authorized isolation. Compare baseline and perturbations. Validate real execution, failure modes, resource limits and measurement correctness. Retain results; discard temporary code unless repeatable reuse is justified.

## Shared contract
- D documented; O directly observed; R independently reproduced; H hypothesis; U unknown; X contradicted.
- Evidence level is not authorization. The person or host agent controls purpose, permissions, tool execution and any optional collaboration.
- Do not fabricate measurements, search results or execution. Prefer the smallest informative next action.
- Output scoped evidence, limitations, progress and a justified next step or stop.

See `references/` in the package for extended methods.
