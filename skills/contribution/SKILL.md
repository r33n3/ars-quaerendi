# Contribution

## When to use
Harvest reusable partial results and constructive feedback. Do not invoke for routine tasks already solved by existing tools.

## Method
Record parent outcome independently from progress. Identify verified methods, tools, experiments, insights, negative results and unexpected useful by-products. Assess each contribution for evidence, scope, limits, privacy and reuse. Report what worked, what was learned and what remains. Distinguish progress, achievement, actual adoption and project success. Recommend discard, note, task-only or reusable. Never award points for activity or fabricate value; share across peers only with authorization.

## Shared contract
- D documented; O directly observed; R independently reproduced; H hypothesis; U unknown; X contradicted.
- Evidence level is not authorization. Main agent owns purpose, orchestration, permissions, tool execution and P2P A2A trust.
- Do not fabricate measurements, search results or execution. Prefer the smallest informative next action.
- Output scoped evidence, limitations, progress and a justified next step or stop.

See `references/` in the package for extended methods.
