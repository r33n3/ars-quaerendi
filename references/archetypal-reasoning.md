# Optional reasoning lenses and narrative summaries

This experimental method requires a user request or an already approved evaluation that includes it. A lens labels a reasoning function. Permissions, identity and collaboration remain controlled by the user and host. Any benefit from the labels remains unmeasured until evaluated.

## Candidate lenses

* Seer: notices anomalies and candidate patterns.
* Scholar: constructs explanatory models.
* Smith: proposes the smallest useful instrument or test.
* Challenger: seeks concrete falsifiers within the stopping rules.
* Guardian: identifies observed hazards, operating boundaries and reversibility.
* Chronicler: preserves provenance, limits and reusable contributions.
* Pathfinder: connects evidence with opportunities relevant to the user's purpose.

Choose the functions relevant to the task. One agent can apply them sequentially. Separate agents require actual authorization for collaboration and a useful division of work.

## Method and presentation

Keep structured method outputs as the source record. An optional narrative summarizes those records for a person. Link each factual statement to its evidence identifier, retain uncertainty and scope, and label hypothetical events. Evidence determines whether the result is supported, contradicted, qualified, unknown or inconclusive. Record consensus as agreement among participants.

Assess whether these human categories fit the subject. For unfamiliar systems, use observed behavior and explicit contracts. Alternative lenses need testable predictions and the same evidence checks.

## Controlled evaluation

Compare four conditions using comparable models, tools, permissions, tasks and budgets:

1. Ordinary task handling.
2. Functional method contracts.
3. The same contracts with lens labels.
4. The same contracts with labels and narrative summaries.

Compare correctness, falsifier quality, hypothesis diversity, transfer, calibration, human comprehension, elapsed time and cost. Check role stereotyping, agreement effects and confidence that exceeds the evidence. Record null results and failures alongside any improvement. State differences in resources or conditions.

Return the mapping between lenses and methods, any requested narrative with evidence references, and measured results or an explicit unmeasured status. Discovery can use lenses to generate leads. Contribution can use a requested narrative to explain retained findings.
