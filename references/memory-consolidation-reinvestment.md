# Preserving useful knowledge

Use this method after a meaningful investigation, correction, reusable result or interruption risk. Keep event records, claims and evidence, procedural methods, temporary checkpoints and retrieval indexes distinct.

Retain mechanisms, operating limits, negative evidence, corrections and provenance. Consolidate repeated summaries while preserving authoritative artifacts. Mark outdated methods as superseded or archived and keep the earlier record available. A correction creates a new record linked to the earlier version.

Store material through an available and authorized mechanism. Follow the user's retention and privacy requirements. Record missing persistence or unavailable sources as unresolved. Keep the parent task outcome separate from a reusable contribution.

Assess future value through verified reuse, successful transfer, avoided repetition and retrieval cost. Treat expected benefits as estimates until observed. Recommendations about further investment remain within the user's purpose and actual resource limits.

Stop when useful knowledge has been indexed, further consolidation adds little value or the agreed budget expires. Contribution can retain the record. Inquiry and Purpose Planning can use it when a later task provides a relevant context.
