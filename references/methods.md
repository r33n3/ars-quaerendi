# Research methods

- SearchLore, SourceTrace and CounterSearch: map terminology, alternate broad and narrow queries, search distinctive fragments and archives, trace citation origins, seek independent corroboration and inspect coverage gaps.
- Lateral Inquiry: reinterpret clues, try alternate encodings, follow promising leads within a set budget, reconstruct the discovery path and test for coincidence.
- System Autopsy and Interface Archaeology: examine symbols, headers, exports, calling conventions, version differences, memory ownership, loader behavior and dynamic traces. Use controlled fault injection on authorized systems.
- Pattern Archaeology: examine hashes, YARA byte matches, parsed regions, entropy and visualizations. Test proposed mechanisms separately from detected patterns.
- Measurement Validity: define the measured variable, controls, confounders, coverage, instrument effects and results that would disprove the explanation.
- ResearchForge: document methods, observations, failures, limitations and reproduction instructions. Publish when requested.
