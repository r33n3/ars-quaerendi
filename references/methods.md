# Research methods

* Search and source tracing: map terminology, alternate broad and narrow queries, search distinctive fragments and archives, trace citation origins, seek independent corroboration and inspect coverage gaps.
* Alternative interpretations: reinterpret clues, try alternate encodings, follow promising leads within a set budget, reconstruct the discovery path and test for coincidence.
* System investigation: examine symbols, headers, exports, calling conventions, version differences, memory ownership, loader behavior and execution records. Introduce controlled failures on authorized systems to test recovery.
* Pattern analysis: examine hashes, matching byte sequences, parsed regions, entropy and visualizations. Test proposed mechanisms separately from detected patterns.
* Measurement checks: define the measured variable, controls, other possible causes, coverage, instrument effects and results that would disprove the explanation.
* Research writing: document methods, observations, failures, limitations and reproduction instructions. Publish when requested.
