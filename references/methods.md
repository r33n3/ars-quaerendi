# Historical methods retained
**SearchLore / SourceTrace / CounterSearch:** topic tablets, yo-yo search, distinctive fragments, archived sources, citation lineage, independent corroboration, search omission analysis.
**Hackmore-style Lateral Inquiry:** reinterpret clues, try alternate encodings, follow bounded weak signals, reconstruct discovery retrospectively and test coincidence.
**System Autopsy / Interface Archaeology:** symbols, headers, exports, calling conventions, version differences, memory ownership, loader behavior, dynamic traces, controlled fault injection on authorized systems.
**Pattern Archaeology:** hashes, YARA byte matches, parsed-region attribution, entropy and visualizations; do not confuse pattern with mechanism.
**Measurement Validity:** define operational variable, controls, confounders, coverage, instrumentation effects and falsifiers.
**ResearchForge:** publish methods, observations, failures, limitations and reproduction instructions.
