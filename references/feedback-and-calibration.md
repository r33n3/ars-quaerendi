# Evidence assessment

Use J0 for exploratory work, J1 for plausible claims, J2 for supported claims, J3 for results verified within the tested scope and J4 for a defined use supported by qualification evidence.

Begin with repeatable checks and source tracing. When interpretation needs review, use a focused challenge and set a limit on revision attempts. Resolve disagreements through evidence and testable counterexamples.

Record the project outcome separately from partial progress, learning, unexpected observations and reusable contributions. A falsified hypothesis can provide a useful research result. Record what a retry changes or tests before running it. Assess contributions through supporting evidence and actual reuse.

Keep anomalies as leads until validation supports a conclusion. The user and host environment control authorization.
