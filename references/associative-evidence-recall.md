# Finding and reconstructing earlier evidence

Use this method when an earlier investigation may help or a claim needs reconstruction after context loss. Search available records by terms, meaning, mechanism, causal structure, constraints and failure mode. Use the host's available search or supplied material. Report unavailable access and missing sources.

For each candidate, retain evidence identifiers, provenance, version, tested scope, uncertainty, contradictions and corrections. Reconstruct consequential conclusions from the original artifacts. Summaries and retrieval scores help locate material; assess the claim through its source evidence.

Compare the original conditions with the current task. Record similarities, differences, proposed transfer and the test needed to assess it. A related mechanism supplies a candidate method whose applicability still needs review. Mark missing source material unreconstructable and leave verification unresolved.

Stop when enough supported context has been recovered, the retrieval budget expires or required sources are unavailable. Return reconstructed findings, unresolved claims and the next useful check. Inquiry can use this record to investigate. Judgment can assess the resulting support.
