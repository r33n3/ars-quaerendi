# Research challenge: Different file hashes

## Investigator task

Two approved binary data containers have different file hashes. Determine whether the values of any named data arrays changed.

The evaluator supplies the files, a description of the format, available instruments and a time limit. Use tools that only read the approved samples. Record what each instrument can inspect and any parts it leaves unresolved.

## Investigation record

* Initial expectations and competing explanations.
* Instrument choices and checks of their behavior.
* Observations linked to the relevant file or named component.
* Tests that distinguish the explanations.
* Failed attempts and changes to the approach.
* Conclusion, coverage, uncertainty and reproduction steps.

Use the smallest check that answers the question. If the available reader covers only part of a file, state which parts were checked and which remain unresolved.

## Explanation questions

What did you expect? Which observation changed that expectation? What did the decisive check establish? Which alternatives remain? How could another investigator reproduce the result? Where could this method apply in another kind of container?
