# Purpose of the illustrative recovery comparison

Compare limited ways to complete an interrupted remote task while preserving its actual completion state, source evidence and operating limits. This invented exercise uses the [interruption report](memory-sources/peer-interruption.md).

The [adaptation record](adaptive-peer-recovery.json) retains two proposed approaches. Their execution, relative recovery time, duplicate effects and costs remain unresolved. Any later test follows current user and host permissions and an agreed resource budget.
