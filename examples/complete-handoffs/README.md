# Complete handoff walkthroughs

These walkthroughs use invented source records to demonstrate how agents can preserve evidence while applying several meta skills. They illustrate record structure and recommendations within the supplied sources. Actual observations and host behavior require their own evidence and evaluation.

| Walkthrough | Route | What it demonstrates |
|---|---|---|
| [Research and reuse](research-review-reuse/README.md) | Inquiry, Judgment, Contribution | A reported comparison remains documentary and its reproduction limits remain open. |
| [Offer review and planning](offer-review-planning/README.md) | Institutional Intelligence, Judgment, Purpose Planning | A conditional promise retains its uncertainty and existing permissions. |
| [Pattern investigation and reuse](pattern-investigation-review-reuse/README.md) | Discovery, Inquiry, Judgment, Contribution | Contradictory evidence and partial coverage survive every handoff. |

Start with a walkthrough's `source.md`, then inspect `evidence.json` and the numbered handoff files. The references, content hashes and per record snapshots make it possible to check that later steps retain the same evidence and limits.
