# Reviewing a request from an unfamiliar agent

This invented example concerns a remote agent requesting resources. The message resembles bargaining, while its motives remain unknown.

Agents can use Institutional Intelligence to inspect the protocol request, verify identity and authority, assess measurable commitments and ask about unclear terms. Preserve the user's goals, permissions and resource limits.

If an approved evaluation includes reasoning lenses, compare their predictions with an interpretation based on explicit protocol contracts. Retain the interpretation supported by observed behavior. Discard a lens that predicts poorly and record the reason. Claims about status, greed, deception or other motives require relevant evidence.
