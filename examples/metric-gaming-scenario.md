# Example: A higher score with fewer completed tasks

This example uses invented records.

A report claims a 95% task completion rate after difficult tasks are excluded. The source records contain 100 received tasks: 82 verified complete, 8 incomplete, 6 failed and 4 excluded.

Counting all received tasks gives 82% completion. Excluding four tasks gives about 85.42%. Compare both calculations with the claimed 95% and identify the definition used in the report.

Record exclusions and changes in task difficulty. Investigate the difference and its cause. Use the corrected figures when planning improvements or recognizing progress. Preserve any separately verified contributions from the work.
